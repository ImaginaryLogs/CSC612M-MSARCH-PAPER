\section{Mid-Project Milestones}
\label{sec:milestones}

\paragraph{Milestone 2 (Week 10) deliverable.} A live demo on the curated AD drugs that shows:
\begin{enumerate}
\item the checked scoring function: on a 16-drug instance, an exhaustive Python check over all $2^{16}$ yes/no patterns confirms that the QUBO's best pattern is a valid $k$-drug combination and equals the exact-search answer;
\item CPU and GPU exact search returning the same best combination and the same tie count;
\item SA in scalar C++, AVX2 assembly and CUDA (v1) making identical decisions for a fixed seed;
\item a first sequential-vs-parallel timing table for exact search and SA;
\item the first best AD combinations for $k\in\{2,3\}$ at two values of $\lambda$.
\end{enumerate}
