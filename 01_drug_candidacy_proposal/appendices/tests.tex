\section{Correctness and Regression Tests}
\label{app:tests}

These tests check that the code computes what the math says. They say nothing about whether a combination works biologically (\Cref{app:eval}) or how fast the code is (\Cref{app:eval}). CPU tests run on every commit; GPU tests run on the GTX 1660 before every round of benchmarks. Each test has one owner.
